# AI-FinTech-Expense-Tracker

AI-powered FinTech expense tracker with smart budgeting, financial analytics, secure authentication, and Gemini-powered spending insights.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the environment variables in `.env` (refer to `.env.example`)
3. Run the app:
   `npm run dev`
